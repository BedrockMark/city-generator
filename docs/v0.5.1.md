# v0.5.1 · 约束生效；楼只有底层占地

> 2026-11-03。决策记录见 `NOTE.md` D38、D39。完整回归报告：`v0.5.1/regress_report.txt`（A = v0.5.0 默认画面，B = v0.5.1）。

## 1. 改了什么
- **约束生效**（D39）：C01–C24 全部改为“生效”，默认画面就会剪枝和修复。C19、C23、C24 只报告，留给阶段 6。
  - C02 门被围死：优先删树（广场删中心树），不降级。
  - C17：地面上的空调外机全部删除。
- **exp-01 平顶空调外机**（`rooftop.ts`）：只放在 Roof_1/3/5/7/10 五种平顶上，60% 的楼放 1–3 台。可以在“实验 ▾”里关掉，或用 URL `e=exp-01:0`。
- **楼只有底层占地是碰撞体积**（D38）：高层在生成的任何阶段都不存在，遮挡只是渲染问题。
  - 取消了“楼后地面”的特殊处理：两轮内院分配、后院用途、草坪向楼后延伸、“楼后物件必须完全被挡住”的检查。D22 已删除。
  - 打包器只按底层占地放楼。高层只要求落在本街区的地块里，不压到街道上（这一条是我加的，你可以否决）。
  - 结果（60 个种子）：主街区的楼从 3.25 栋增加到 5.23 栋，后排楼从 0.8 栋增加到 2.8 栋；停车场 22 → 42 格，花园 112 → 130 格。
  - 前排楼的高层会盖住后排楼的立面、门、停车场和车。你已确认保留这个效果。
