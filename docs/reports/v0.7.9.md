# v0.7.9：宫殿花园（exp-09，实验）

2026-11-08，分支 `master`。

用户的要求：宫殿是一个特殊建筑，有自己的模块化贴图；它要和花园连接，花园围绕它在后面一圈，大棚（温室）放进去，要用上花园墙；前景要有下车处（drop-off area），车道外要有一片草坪或喷泉广场。其余合理的需求由我补全，做成实验功能，在菜单里加上并在名字前加“[exp]”。

**第二轮**（同日，看了第一版）：第一版的布局可以作为一种参考，但不应该每座都这样。大小相当于 2–3 个普通街区。可以随机打破对称，留出更大的后花园，后花园里可以有泳池、游乐场、花园迷宫、大温室（每个种子选一个或几个，保持随机）。重点是避免固定的、一格一格的规律（每个功能区围起来可以）。通道和下车处保持现在的样子。

## 1. 怎么用

- 顶栏最左边的下拉菜单最后一项：**[exp] 宫殿花园**；URL `?seed=3&d=palace`；代码 `generate(seed, { district: 'palace' })`；批量 `npx tsx scripts/batch.ts ../work/gen --d=palace 1..8`。

- 产物全部带 `exp: 'exp-09'`，标注层是粉色虚线和“实验 exp-09”标签。

## 3. 素材

- **宫殿**：`17_Garden/Palace_Example_1`（黄墙）、`_2`（棕墙），25×34 格。上 29 行是楼（立面在第 29 行），中间 7 列的台阶再往下 5 行。
- **宫殿的模块化贴图**：`Palace_<n>_Entrance_Variant_1/2/3`（7×4，无柱 / 四柱 / 两柱门廊，盖在精灵的 (144, 400) px 上；示例图用的是 2）；`Variant_4`（3×4）其实是上下两块 3×2 的“大门敞开”：上半块配无柱 / 两柱门廊，下半块配四柱门廊，盖在 (176, 400) px。为了只画一部分，场景物件加了 `clip: [x0, y0, x1, y1]`（只画贴图里的这个矩形），Phaser 查看器和 Python 渲染器都支持。
- **树篱**：`Grass_Wall_2`（高树篱，画两格高：上面一格是顶，下面一格是正面）做花园墙，`Grass_Wall_1`（矮树篱，一格）围功能区。编号从整合图上读出来：9 / 10 / 11 横向左端 / 中段 / 右端，1 / 3 / 7 / 5 四个角，竖向的上端 / 中段 / 下端矮树篱是 12 / 13 / 14、高树篱是 13 / 8 / 12。素材包只有十字路口（25），没有 T 字：迷宫里的 T 字 = 十字 + 盖上一条直段的封口边（`clip` 取 10 或 13 的一条边）。
- **铁门** `Gate_1/2`（3×2）正好嵌在高树篱里。
- **大温室**：`Large_Greenhouse_Example`（8×7）的第 1、6 列是模块化的列（和 `Greenhouse_*_Modular` 一样），重复这两列就能加宽到 8–16 格，用 `clip` 一列一列画。小温室 `Small_Greenhouse_Example`（4×6）。
- **泳池**（新加入素材清单：`tools/export_manifest.py` 的 `PACKS` 加了 `14_Swimming_Pool`）：池边 1 / 2 / 3（上）、8 / 4（两侧）、7 / 6 / 5（下），池底瓷砖 20 / 21 / 22（第一行）、19 / 23 / 24，扶梯 39；躺椅、遮阳伞、小桌、棕榈树、救生圈架、充气玩具。
- 游乐场用学校的 `School_Yard_Toy_*`；其余：树篱拱门 `Grass_Arch_1/2`、喷泉、雕像、石柱、动物造型树篱、花架、花、幼苗、长椅、推车、木箱、工具架、耙子、浇水壶、鸟屋、园丁小屋 `*_Wood_Storage`。

## 4. 布局

### 不变的部分（用户：通道和下车处保持）
- 北 → 南：花园 | 宫殿（整栋立在地块上）和台阶两侧的花坛 | 下车处（台阶脚下 4 行车道，一进一出两条车道，车、司机、客人、两名卫兵）| 两条车道之间临街的草坪或喷泉广场。
- 花园外沿是高树篱花园墙；绕宫殿 2 格宽的步道，两侧通到南街。宫殿后面的步道改成横穿整个花园（第一版只在宫殿后面）。

### 大小和比例（第二轮）
普通街区内部约 550 格，2–3 个加上中间的马路约 1700–2600 格。每个种子先抽一种比例，保证至少有一块地放得下一个功能区：

| 比例 | 后花园 | 两侧 | 种子 1–40 |
|---|---|---|---|
| 后花园深 | 16–24 行 | 按面积分给两侧（随机比例，至少 4 列） | 最常见 |
| 两侧宽 | 6–10 行 | 各 12–16 列 | |
| 一侧宽 | 6–14 行 | 一侧 13–20 列，另一侧 4–5 列 | |
| 均衡 | 13–16 行 | 按面积分 | |

种子 1–40 的内部面积 1947–2793 格。30% 的种子（“一侧宽”除外）左右对称：两侧宽度相同、地块左右镜像。

### 花园怎么分（第二轮）
- 后花园和两侧花园各是一大块地，随机切开：每一刀要么是一条小路（随机 1 格的花园小路或 2 格的步道），从一条已有的路切进去；要么是背靠背的两块。这样每一块都挨着至少一条路。长边更容易被切（一侧 40 行的窄条不会留成一整块）；放得下某个功能区、又不比它大太多的块，多半留整块给它。
- 每个种子抽 1–3 种功能区（泳池、迷宫、游乐场、大温室），每种放进一块放得下的地，优先尺寸贴合的块；最多试 12 种切法，取放下最多的一种。只考虑这个种子的地形放得下的功能区。没放功能区的大块（> 110 格）接着切。
- 其余的块：树篱围起的小花园（雕像 / 小喷泉 + 长椅 / 花圃 / 花架凉亭 / 动物造型树篱）、不围的草地（随意种树、灌木、花，偶尔一张长椅或鸟屋）、园丁小屋（一处）、小温室（没有大温室时一处）、窄条（一行灌木或花）。开口开在挨着路的一边、位置随机，横向的开口有时有树篱拱门；靠花园墙的一边不再围矮树篱。
- 后院庭院（中轴上的喷泉 / 雕像，两边长椅）：对称的种子 60%，其余 30%。对称又没有庭院时，中轴上一条 3 格宽的路通到花园墙。
- 铁门：有路或庭院通到北边的花园墙时，80% 在那里开一道铁门；没开门的小路尽头靠墙立一座雕像 / 石柱。
- 种子 1–40 里：迷宫 19 个、泳池 16、游乐场 18、温室（大或小）27、园丁小屋 18、庭院 13；每个种子至少一种功能区。

### 功能区
| 功能区 | 内容 |
|---|---|
| 泳池 | 矮树篱围着的铺地（浅灰 / 浅米 / 蓝色池畔砖），池子大小随块变（水面 3–12 × 2–5），扶梯，水里 0–2 个充气玩具；下面一排躺椅，间或遮阳伞、小桌；角上棕榈树；救生圈架；池边的人 |
| 迷宫 | 整块是一座迷宫：奇数格上随机生成树（深度优先），矮树篱墙（含 T 字和十字），路面铺地；入口开在挨路的一边，60% 另一边还有出口；11×11 以上中间有一块 3×3 的空地，放小喷泉或小雕像；迷宫里 1–3 个人 |
| 游乐场 | 矮树篱围着的草地，2–6 个游乐设施（不重复），入口旁家长坐的长椅，孩子和家长 |
| 大温室 | 加宽的大温室（8–16 格）靠在块的后面，门前两行铺地通到开口，下面一行行幼苗，旁边工具架、木箱，门边耙子，园丁 |

## 5. 约束和回归

- 种子 1–40 的宫殿花园：约束修复没有删掉、降级园区里的任何东西；剩余违规只有种子 18 的 1 条 C24，在邻近街区（楼顶空调挡门），和宫殿无关。245 个功能区 / 小花园里没有空的（第二轮第一版有花架凉亭放不进 3 格宽的小花园、留下空的树篱框，改为放不下时放盆栽和花）。
- 普通街区 200/200 和 v0.7.8.2 完全相同（`work/regress/v0782` → `work/regress/v079`；加入泳池素材包也没有改变）。
- 55 项测试通过（`src/gen/palace.test.ts`：每个种子至少一种功能区、没有空的功能区、面积在 1700–2900 格、实验标记、两条车道、花园在后面和两边、没有被修复删掉；查看器混入不会抽到宫殿）。

## 6. 顺手修的

- **查看器绘制合批**：查看器把地面和物件一个个画到 RenderTexture 上（每个一次 `drawFrame`）。宫殿图有几百段树篱、每段一张单独的贴图，在无头浏览器（软件 WebGL）里导出截图要 130 秒（学校 31 秒），`shots.ts` 的点击超时。改成一次 `beginDraw` / `batchDrawFrame` / `endDraw` 以后 0.7 秒；普通街区导出的 PNG（正常 + 虚化版）和改之前逐像素相同。

## 7. 需要你看的

1. 大小：现在 1950–2800 格（大约是普通街区的 3.5–5 倍内部面积，算上合并掉的马路约 2–3 个街区）。偏大还是合适？
2. 路的密度：有的种子小路切得比较碎（铺地多）。要不要少切几刀、让草地和功能区更大？
3. 功能区的频率：现在每种约 1/3–2/3 的种子有，温室（大或小）最多。
4. 迷宫靠着花园墙时，迷宫外墙和花园墙是两道树篱并排。可以接受吗？
5. 背靠背的两个小花园之间也是两道矮树篱并排（第一版没有这种情况）。
