# docs/

Everything written about the project lives here: the brief, the decision log, the session hand-off, the experiment register, the design specs, the user-facing technical reports and the retired records. All of it is in Chinese (the user's language) and most of it is the project's working memory: `BRIEF.md`, `NOTE.md`, `PROGRESS.md` and `EXPERIMENTS.md` are read at the start of every session and updated as work proceeds. The code these documents describe is in [`../app/`](../app/README.md) (TypeScript generator + Phaser viewer) and [`../tools/`](../tools/README.md) (Python analysis); the reference maps and user labels they refer to are in [`../references/`](../references/README.md).

Layout convention (PROGRESS.md, 2026-11-05): the `docs/` root holds only hand-off files; `reports/` holds user-facing technical docs, generated tables, figures and the version reports that still have open questions; `_prev/` holds record-only files that keep their original directory structure.

## Commands

All commands below are verified; the working directory is shown.

| Command | Produces |
|---|---|
| `cd app && npx tsx scripts/constraints.ts doc [n]` | Rewrites `reports/CONSTRAINTS.md` from `app/src/gen/rational/constraints.ts` over `n` regression seeds. The reference-map column needs `cd tools && uv run python export_refworld.py` first. |
| `cd app && npx tsx scripts/prefs.ts eval` | Rewrites `reports/PREFS.md` from the current labels and choices. |
| `cd app && npx tsx scripts/prefs.ts train` | Retrains the preference multipliers into `app/src/gen/data/prefs.json` (the input of PREFS.md). |
| `cd app && npx tsx scripts/regress.ts snapshot-par ../work/regress/<name> --jobs 8` then `npx tsx scripts/regress.ts report <dirA> <dirB>` | Snapshots 200 regression seeds (about 40 s) and writes the text used for `regress_report.txt` files in version report folders. |
| `cd app && npx tsx scripts/shots.ts <outDir> [--anno] [--q=d=school] 2 3 5` | Captures viewer screenshots for version reports; `npx vite` must be running on port 5173. |
| `cd tools && uv run python make_figs.py` | Rebuilds `reports/fig/*.png` from the reference maps (needs the gitignored reference maps and `work/refs`). |
| `cd tools && uv run python make_readme_figs.py` | Rebuilds `readme/*.png` from viewer exports in `work/readme_shots/` (see the script header for the `shots.ts` calls that fill it). |
| `cd tools && uv run python eval_generated.py <scene.json ...> --out report.md` | Writes a metrics table like `_prev/stage2/eval.md` (needs the analysis artefacts in `work/`, see `tools/README.md`). |

## Notes

- Everything here is Chinese. `BRIEF.md`, `NOTE.md`, `PROGRESS.md` and `EXPERIMENTS.md` are the hand-off set the project `../CLAUDE.md` asks to read before any work; for current behaviour trust `PROGRESS.md` ("代码结构") and the latest version reports over `reports/methodology.md`, which is explicitly as of v0.5.1.
- Images: only `readme/*.png`, `reports/fig/*.png` and `_prev/fig/anti_crop.png` are tracked. Every other PNG under `docs/` (version-report screenshots in `reports/v0.7.<n>/`, renders and heat maps in `_prev/`) is gitignored and exists only on the author's machine; the text and JSON next to them are published.
- `reports/CONSTRAINTS.md` and `reports/PREFS.md` are generated and carry their own header stating so; they lag the current generator (CONSTRAINTS at v0.7.6, PREFS at v0.7.0). Re-run the scripts instead of editing.
- `EXPERIMENTS.md` describes experiment switches (URL `x=` / `e=`, the "实验" menu) that were removed in v0.7.6; all surviving experiments are adopted and untagged in the code.
- `reports/v0.7.0/prefs_eval.txt` mentions writing `docs\PREFS.md`; that file moved to `reports/PREFS.md` on 2026-11-05.
- `_prev/reports/JUDGE.md` and the stage 6 material cannot be reproduced from the current code; check out tag `v0.7.5` if you need the judge.
- `.superpowers/` is ignored by its own `.superpowers/sdd/.gitignore`, not by the root `.gitignore`.
