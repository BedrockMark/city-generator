## 1. 改了什么
- **“修复预览”复选框 → “整体修图”复选框**（顶栏，默认关；URL `e=exp-02:1`）。它就是实验 exp-02 的开关，“实验 ▾”菜单里不再单列 exp-02。实验总开关关掉时它变灰。
- **整体修图只重新打包主街区**：
  - 整图怪异分平均高于参考图的 90 百分位时，用 4 种盐重新打包；
  - 取约束不变差、平均分最低的一种，都不如原图就保留原图；
  - 每张图约 2–5 秒，顶栏显示进度；
  - 导出的场景 JSON 记着采用的盐，能原样重现。
- **删掉了**：逐窗口换盐、降级、热力图上的修复框、URL `pd` / `jg`。
- **代码审查的问题**：
  - 修好了：拖入场景 JSON 时，正在跑的生成不会再覆盖它；Worker 出错会提示；进度计数正确。
  - “给行人随机流加盐”随局部档一起消失。
- **更正**：v0.6.0 报告里写的“6 种打包”实际是 4 种，已在 `v0.6.0.md` 改正。
