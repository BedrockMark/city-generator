## 生成器做了什么（对应阶段 1 的方法）

1. **街区形状和尺寸都随机**：
   - 内部面积 560 格 ±30%，宽高比 1.05–1.9；
   - 形状有四种：矩形；单边错位（jog，相邻街道随之错开）；缺角（notch，缺角处是一个由短街围出的小岛街区，形成 T 字路口）；缺角加错位。
   - 道路：双车道 5 或 7 格，东西向可以是 9 格宽路，宽度都取奇数，保证中心虚线落在格子中间。人行道 2–3 格。
   - 四周加上邻近街区和延伸出去的街道，整张图的尺寸随之变化。
2. **地面**：
   - 人行道用 GMS 47 格 blob autotile 自动生成路缘和转角，6 种颜色；内部用同色的石板纹理。
   - 沥青有 10 种变体，带少量裂缝。
   - 中心虚线和人行横道由“道路连续长度”自动推出：在交叉口前断开，横道条纹方向正确。每个路口只放 0–2 条横道，靠近主街区的更可能有。
3. **建筑**：
   - 模块化楼（屋顶 + 0–3 层中间层 + 底商）：同一栋楼颜色统一，底商的招牌可以盖到上一层。底商有 Plume / Groove / Coolies / Bim Bum / 冰淇淋 / 面包 / 肉铺 / 健身房 / 音乐店 / 公寓入口等，约 15% 拉下卷帘门。
   - 完整单体建筑：公寓、红砖大楼、市场、五金店、联排住宅等。
   - 相邻两栋模块楼有时共用颜色和高度，形成连续立面，但底商绝不重复同一种。
   - 只有面向街道的楼才能是商铺，内院里的楼只能是住宅。
4. **地块**：
   - 统一的“打包器”：从最低的一行开始，把建筑底边对齐放下；面朝另一栋楼背面的楼要留 2 行前院。
   - 沿街先挖出 0–2 条巷子和 0–1 个小广场。
   - 剩下的内院按大小和是否临街，变成垂直停车场、横向停车位、花园（草地 + 小树 + 长椅 + 人，临街一侧有带门的围栏）之一，再在角落加垃圾箱、晾衣绳、纸箱这类杂物。
5. **功能小组**（每个物件都有理由）：
   - **人行横道**：两端（或一端）放红绿灯杆，杆上带过街标志，有时有人在等。
   - **路缘节奏带**：每条街选一种节拍，比如树–灯、只有树、护柱、花箱–护柱、灯–护柱–护柱。间距 24–120px，带 ±3px 抖动，12% 的位置随机换成垃圾桶、标牌或长椅。遇到横道口、门口、巷口、公交站就断开。邻近街区的街道更朴素，有的只有灯，有的什么都没有。
   - **店门**：
     - 咖啡 / 冰淇淋 / 面包店：桌椅组、坐着的顾客、立牌；
     - 零售：门两侧的盆栽、立牌、垃圾桶、看橱窗的人；
     - 住宅：花箱、信箱、住户；
     - 关门的店：门口有垃圾。
   - **公交站**：候车亭 + 站牌 + 坐着和站着等车的人 + 垃圾桶。
   - **路边停车**：车停在靠路缘的车道上，车头方向符合右侧通行；有时旁边有咪表。偶尔有行驶中的车。
   - **巷子**：巷口内侧放垃圾箱或垃圾桶、垃圾袋，偶尔有人在看手机。
   - **小广场 / 小岛**：中心放喷泉、树、售货亭或广告牌，两侧对称放长椅和灯，再加几个人。
   - **道路**：井盖；约 25% 的种子有道路施工（坑 + 锥桶 + 路障 + 工人）。
6. **人物**：
   - 按 CHARACTER_GENERATOR 的顺序叠加图层。
   - 职业服装只在有理由时出现（警察 / 邮差 / 工人 / 厨师等角色由小组指定），其余随机便装，有时加背包、帽子、眼镜。
   - 姿势有站、走、坐、看手机，方向朝向小组的焦点（顾客朝橱窗，等车的人朝路）。

## 我对照参考图的自评

**像的地方：**
- 路缘有设施带，路口有红绿灯，车停在路边车道，公交站一组，店门口有对应的桌椅、立牌和顾客，巷口有垃圾箱。这些都对应参考图里统计出来的关系（3.1 节的 lift 表）。
- 没有反例那种大片空白人行道，没有整块复制，不同种子之间差异明显（街区形状、街道错位、建筑组合、内院用途都在变）。
- 小岛上的咖啡亭、带门围栏的花园、卷帘门店门口的垃圾，这类小细节开始有“叙事感”。

**不像 / 不足（按我认为的严重程度排序）：**
1. **建筑的“剪影”太单一**：模块楼都是 7 格宽，屋顶多为平顶灰色，而且屋顶上是空的。参考图里屋顶上有空调、天线、晾衣、水箱、人，楼宽也更自由（模块 1 格宽的条带可以拼出任意宽度）。这是目前最“像程序生成”的地方。
2. **街面还不够密、不够热闹**：参考图（如 shop_on_street、town_near_river）的店门口有更多层次：遮阳篷、招牌、货架、自行车、人群对话。原型的人偏少、偏孤立，没有成组聊天的人。
3. **内院有时还是灰色空地**：比如种子 5 右下角。打包器剩下的不规则边角还没有被利用。
4. **红绿灯和横道偏多**：小岛街区周围尤其明显，显得“交通设施过剩”。
5. **建筑和地面之间缺少过渡**：楼前没有台阶、门垫、门前小块铺装，楼侧没有空调外机和管道。参考图里楼与街面之间有很多这类小东西。
6. **路边停车没有画车位线**：参考图里有白线和 P 字。
7. **邻近街区只是背景**：内容比主街区简单很多。这是有意的，但边缘有时能看出“被裁切的楼”。
