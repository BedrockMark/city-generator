另外修了几个 bug：
- 巷子被并进了内院，导致停车场画在巷子上，垃圾箱也出现在停车场里；
- 巷口的禁放区登记得比公交站晚，公交亭会挡住巷口；
- 公交站现在会找一个不挡门、横道、巷口和车道的位置；
- 广场和小岛的地面是逐格随机换色的（棋盘格），现在改成整块一种颜色；
- 道路施工的坑放不下时，就不再单独放锥桶；
- 缺角街区的巷子尽头可能伸出街区，现在限制在街区内部。

你喜欢的东西都保留了：小岛街区、小绿地、特殊建筑、相连的同色楼、过道、前后院交错、路边停车、内部街道、绿化带、邻近街区的合并大楼。

## 自动评估

`docs/v0.3.0/eval.md` 增加了两项指标：
- **设施站在车道上**：除车辆、井盖、施工外的物件，脚下是车道的数量。
- **人行道中线被挤占的百分比**：人行道中线上可通行宽度不足 16px 的比例。

| 指标（30 个种子平均） | v0.2.0 | v0.3.0 |
|---|---|---|
| 设施站在车道上（总数） | 85 | **0** |
| 人行道中线被挤占 | 21.8% | **9.7%** |
| 抄袭 / 自我重复 / 种子之间的重复 | 0 / ≈0 / ≈0 | 0 / ≈0 / ≈0 |
| 最大空地块（格） | 66 | 91 |

最大空地块变大了。我查了最大的几块，主要是**停车场的沥青面**（车只算一个点）以及车道。另外路缘设施确实比 v0.2 少，这是按你“路灯过多”“毫无意义的街边装饰”的评价有意减少的。如果你觉得某些街道现在太空了，告诉我是哪里，我再调整。

## 我自己看到的不足（下一版候选）

1. **屋顶还是空的**：参考图的屋顶上有空调、晾衣、天线、人（如 shop_on_street）。这是现在最像“程序生成”的地方之一。
2. **后院的东西只在虚化视图里看得到**。正常视图里，楼后的物件大多被楼挡住，只有超出屋顶的部分露出来。这符合你“碰撞体积 = 屋顶大小”的定义，但想请你确认这是不是你要的效果。
3. 花园偶尔被切成很窄的两条草坪（比如 439865 上部），看起来像两条绿化带。
4. 停车场旁边可能留出一条没有车位的沥青边。
5. 路边停车还没有车位线和 P 字。

## 需要你判断的问题

1. **虚化视图**：现在只是一个可选的查看 / 导出模式，正常视图不虚化。你希望默认就虚化，还是保持现在这样？
2. **路缘设施的密度**：
   - 路灯：主街区约 30% 的街道没有，邻近街区约 65% 没有。
   - 树、花箱、护柱：主街区南侧约 20% 的街道一样都没有，北侧约 40%。
