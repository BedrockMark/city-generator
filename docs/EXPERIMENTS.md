# 实验功能登记

> 规则见 `docs/BRIEF.md`“实验功能（定义）”。代码中的登记表：`app/src/gen/exp.ts` 的 `EXPERIMENTS`，两处保持一致。

## 框架（v0.4.0 起）
- **编号**：`exp-NN`，按申请顺序递增，不复用。
- **开关**：
  - 查看器顶栏“实验 ▾”：总开关 + 逐个开关；URL 参数 `x=0`（总开关关）、`e=exp-01:0,exp-02:1`（逐个）。
  - 代码：`generate(seed, { experiments, exp: { 'exp-01': false } })`。
- **独立随机流**：实验只从 `expFires(opts, id, rng)` 返回的 `rng.fork('exp/<id>')` 取随机数，所以关掉它时其余随机流不变，同一种子的其余部分尽量不变。
- **触发概率**：登记项可带 `fire(novelty)`，创新度越高越容易触发（阶段 7 正式使用）。
- **标记**：实验代码在 `sb.withExp(id, () => …)` 里放置。它产生的物件、小组和区域都带 `exp: '<id>'` 字段，标注层用粉色粗虚线和“实验 exp-NN”标签显示。
- **状态**：实验 → 转正（变成普通生成逻辑，去掉标记，始终开启）/ 废弃（不再运行）。依据是用户对其产物的好 / 坏标注，转正或废弃前先向用户确认。
