## 2. 环岛

### 2.1 素材
- `2_City_Terrains_16x16.png` 每个铺地颜色块（`gen/layout.ts` 的 `SLAB_BLOCK`，偏移 `(bx, by)`）里，环岛在 `(bx + 14 .. bx + 28, by + 9 .. by + 21)`，15 × 13 格。六种颜色的沥青、虚线格相同，只有铺地部分不同。
- 原图：进出口每臂 3 格（第 20–22 列 / 第 14–16 行，路缘画在这几格的边上），中间一圈椭圆虚线（第 16、26 列，第 11、19 行），中心一个小岛（第 19–23 列 × 第 13–17 行内）带一块环岛标志（标志画死在地面格里，没有单独的精灵）。

### 2.2 选哪些路口（`world/roundabout.ts`）
- 路口 `(i, j)` = 竖向主干道 `i` 和横向主干道 `j` 的交点。`isRoundabout(seed, i, j)`：`hash01(seed, 'rb', i, j) < ROUNDABOUT_CHANCE[zone]`，`zone` 取名义交点 `(i·S.x + vJitter(i), j·S.y + hJitter(j))` 的 `zoneAt`（不经过错位，避免循环依赖）。
- `ROUNDABOUT_CHANCE = { downtown: 0.2, mixed: 0.35, residential: 0.35 }`（`config.ts`）。
- 环岛两边的四段主干道不错位：`vLine(seed, i, j)` 在 `isRoundabout(i, j)` 或 `isRoundabout(i, j + 1)` 时 jog = 0，`hLine(seed, j, i)` 在 `isRoundabout(i, j)` 或 `isRoundabout(i + 1, j)` 时 jog = 0。所以环岛四臂对齐，格的边可能动，这些格重新切。

### 2.3 几何
- 记 `x0` / `Wv` = 竖向主干道的左边和宽，`y0` / `Wh` = 横向主干道的上边和宽。环岛矩形 `R = [x0 − 6, x0 + Wv + 6) × [y0 − 5, y0 + Wh + 5)`（11 × 11 时 23 × 21，17 × 11 时 29 × 21）。
- 九宫格拉伸：输出列 `u = x − (x0 − 6)`，源列 `c(u) = 14 + u`（`u < 7`）、`21`（`7 ≤ u < Wv + 5`）、`u − Wv + 17`（其余），即源第 20 列落在 `x0`（`u` = 6）、第 22 列落在 `x0 + Wv − 1`，第 21 列重复 `Wv − 2` 次；行：`v = y − (y0 − 5)`，`r(v) = 9 + v`（`v < 6`，源第 14 行落在 `y0`）、`15`（`6 ≤ v < Wh + 4`）、`v − Wh + 12`（其余，源第 16 行落在 `y0 + Wh − 1`）。虚线在 `u` = 2、`Wv + 9`，`v` = 2、`Wh + 7`。
- 格的类别：源格里沥青像素（源 `(15, 1)` 的 3 种颜色）≥ 128 个是 `road`，否则是 `walk`（属于所在的角街区）。这个 15 × 13 的类别表写死在代码里（数据来自素材；`tools/` 脚本可以重新导出，见计划）。
- 中心小岛（2.4）：`[x0 − 1, x0 + Wv + 1) × [y0, y0 + Wh)`（内圈虚线到小岛两条车道宽）。`ROUNDABOUT_ISLAND = { x: 1, y: 0 }` 是向外扩的格数。
- 四个角：`R` 和四个主干道格的交（每个角 6 × 5）里 `road` 的格从那个角街区的占地里挖掉（`BlockRec.cut`，见 2.5），`walk` 的格留给它当人行道。
- 小岛框（源第 19–23 列 × 第 13–17 行，标志和原来的小岛）在输出里一律画成沥青（小岛街区的格除外）。

### 2.4 小岛街区
- id `r<i>,<j>`，`shape: 'roundabout'`，`cell: [i, j]`，`sw` 2，分区 = 2.2 的 `zone`，铺地按分区散列，`foot` = 2.3 的小岛矩形，`why` 写路口、两条主干道宽、概率、小岛大小。
- `blockAt` / `blockById` / `cellBlocks` 之外的光栅（`cells.ts` 的 `raster`）都要认得它。
- 生成器（窗口、`shape === 'roundabout'`）：不放楼、不放人、不放长椅和亭子；地块铺草（`district.ts` 的 `lawn`），中心一个主物（喷泉 / 雕像 / 大树，从中心广场的中心物里选，`centre.ts`），四角小树或灌木，可加花坛。新小组 `roundabout`，区域 `roundabout`（不在 C17 / C18 / C25 的目标列表里：这个岛不让人进）。流 `roundabout`。

### 2.5 世界层改动
- `BlockRec.cut?: Rect[]`：占地里挖掉的格（行段）。`inFoot` = 在某个 `foot` 里且不在任何 `cut` 里；`raster`、`lotOf` 跟着变。`foot` 的含义不变（外接矩形们）。
- 环岛角上不放缺角小岛（`notch` 的小岛矩形和 `R` 相交就不切），特色街区预留的角不选环岛角（`reserveCorner` 的 8 种里跳过占地和 `R` 相交的）。
- 地面（`ground.ts`）：先照常画，再对 `R` 里的格：小岛街区的格不动；源格在小岛框里或者源格就是纯沥青 `(15, 1)` → 世界沥青（散列）；`walk` 格且 8 邻都不是 `road` → 不动；其余 → 环岛素材格 `['city', bx + c, by + r]`，颜色块取这一格所在象限的角街区的铺地。`mark` 记 `'roundabout'`。
- 车道线、横道、窗口路段：`findSegs` 时把 `R` 里的 `road` 格当成非马路，所以主干道的路段停在 `R` 的边上，车道线在边前一格结束。
- 横道：路段尽头的下一格在 `R` 里 → 当作路口（不查横路），按 `CROSSING_CHANCE.arterial` 散列（键含 `'rb'`、`i`、`j`、臂）。
- 窗口（`window.ts`）：生成器对 `R` 里的格的地面改动丢掉（恢复世界地面）；`R` 里 `road` 格上的物件丢掉（小岛街区的物件不受影响）。

### 2.6 检查和测试
- 单元：`isRoundabout` 只看散列和分区；环岛两边的段 jog = 0；`R` 的四角挖掉的格不属于任何街区、`walk` 的格属于角街区；小岛在 `R` 正中；拉伸映射在 `Wv` = 11 / 17 时源第 20 / 22 列分别落在 `x0` / `x0 + Wv − 1`；地面在 `R` 里不出现源小岛框的格；负坐标。
- 世界回归新增检查“环岛”：每个环岛 `R` 里没有别的街区的 `lot` 格，四臂对齐，小岛街区存在且没有楼；报告列环岛个数（按宽度组合）。

## 3. C26 街区可达（只报告）

- 平地世界里每个街区的人行道都挨着马路，C26 在 v0.8.3 的意思是：**从这个街区能走横道离开**。判定（`world/reach.ts`，`blockReach(seed, blockId)`）：街区的人行道格里有一格和某条横道的一头相邻（4 邻，横道两头各一格人行道）就通过。不看物件挡路（物件挡人行道由街区内的约束管）。
- 豁免：`shape === 'roundabout'`（不让人进），`why` 写原因。
- 结果：`worldInfo` 对街区格加一条“可达：经 n 条横道”或“C26：没有横道通到这个街区”；世界回归报告列违规数和例子（只报告，状态和 C19 / C23 一样）。是否改成修复（例如补横道，违反“宁删勿补”需要用户同意）问用户。

## 4. 世界层可解释性补全

`worldInfo` 的 `why` 补：
- 主干道：这一段的错位（`jog` 格数，散列；环岛旁的段写“环岛两边不错位”）。
- 环岛格：路口、两条主干道宽、概率、这一格是环岛的哪部分（臂 / 环道 / 角）。
- 横道格：属于哪个路口的哪条臂、概率、离路口几格。
- 车道线格：双实线 / 虚线的原因（几车道、每条线一格）。
- 特色街区：城市里地标的选择（`campusFor` 选到的地标精灵、园区大小）写进街区 `why`（v0.8.2 已知问题“城市里地标的选择不进 trace”）。

- 支路路口的环岛（只有主干道路口）。
