# v0.8.3 主干道路口环岛、C26、世界层可解释性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 部分主干道路口变成用素材拼的环岛（中间一个绿岛街区），新增只报告的 C26 街区可达，世界层每个决定都能在悬停里看到原因，修好城市里购物中心缺地下停车场入口；单街区模式画面不变。

**Architecture:** 新文件 `world/roundabout.ts` 负责选路口、几何（环岛矩形、九宫格拉伸映射、类别表、小岛矩形）；`arterials.ts` 让环岛两边的段不错位；`blocks.ts` 给角街区挖掉 `cut`，并把小岛街区 `r<i>,<j>` 接进 `blockAt` / `blockById` / `raster`；`ground.ts` 在环岛矩形里铺素材格；`findSegs` 的调用方把环岛里的马路当成非马路，路段、车道线、横道都停在环岛边上。生成器只多认 `shape === 'roundabout'`（不放楼的绿岛）。C26 在新文件 `world/reach.ts`，只报告。

**Tech Stack:** TypeScript（`tsx --test`、`node:test`、`node:assert/strict`），Node 脚本（`regress.ts`、`cityregress.ts`、`cityshot.ts`、`shots.ts` + headless Edge），Python 渲染（`tools/render_generated.py`，`uv run`）。

**Spec:** `docs/superpowers/specs/2026-11-12-v083-roads-design.md`。总 spec：`docs/superpowers/specs/2026-11-11-v1-city-design.md`（第 7、8、10 节）。世界层文件见 `app/src/world/README.md`，生成器见 `app/src/gen/README.md`。
