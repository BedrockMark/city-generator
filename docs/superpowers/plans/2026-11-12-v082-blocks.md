# v0.8.2 繁荣度、大街区中心广场、特色街区占地、分区参数 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 城市里的街区大小由繁荣度连续决定（闹市小、住宅大，约 16–56 × 12–40），大街区中心留出广场 / 中庭并有通道进入，特色街区按园区大小在主干道格的一角占地，分区参数表（楼型、店铺、拼接楼、套件、临街小广场）接到生成器；单街区模式画面不变。

**Architecture:** 世界层（`world/blocks.ts`）在切分前按主干道格中心的 `zoneValue` 插值地块范围，按散列在格的一角预留特色街区（园区大小来自新函数 `gen/district.ts` 的 `campusFor`，世界层和生成器共用），切完后给大矩形街区标 `centre`。`world/window.ts` 把分区参数、`centre`、`district` 通过 `BlockWindow.city` 和 `opts.district` 交给生成器；生成器只在有 `city` 时改权重 / 概率、刻中心区和通道（`gen/block.ts` + 新文件 `gen/centre.ts`），所以 `generate(seed)` 不变。

**Tech Stack:** TypeScript（`tsx --test`、`node:test`、`node:assert/strict`），Node 脚本（`regress.ts`、`cityregress.ts`、`cityshot.ts`、`shots.ts` + playwright-core / headless Edge），Python 渲染（`tools/render_generated.py`，`uv run`）。

**Spec:** `docs/superpowers/specs/2026-11-12-v082-blocks-design.md`（本计划覆盖它的第 1–5 节）。总 spec：`docs/superpowers/specs/2026-11-11-v1-city-design.md`（第 10 节 v0.8.2 一行）。世界层文件见 `app/src/world/README.md`，生成器见 `app/src/gen/README.md`。

## Review Focus

1. **特色街区在格里放不下**（园区比格大，或剩下的部分切不开，例如闹市里 48 宽的医院）：期望不放特色街区，格照常切开，第一个街区的 `why` 写出“抽到…但 8 种预留方式都切不开”。→ Task 2 测试 `reserveCorner returns null when nothing fits` 和 `a cell that draws an unplaceable district still splits, with the reason`。
2. **插值出来的范围切不开格的边长**（例如 `t = 0` 时高度目标 24–44 占地，格高 45–52 落在 1 块和 2 块之间的空档）：期望把上限放宽到可行，`why` 写“放宽”，不抛错。→ Task 1 测试 `widenToFit raises the upper bound until the length is feasible` 和 `every cell splits and every lot is within its cell's range`（30 种子 × 7 × 7，含负坐标）。
3. **偏好 / 创新度改变园区大小**：世界层预留的地块和生成器里的园区必须一样大，不管 `prefs` 开关。→ Task 2 测试 `a district block generates its landmark on a lot of exactly the campus size`（`prefs: true` 和 `prefs: false` 都查 `params.interior`）。
4. **窗口边距变了，中心区 / 通道 / 园区跟着变**（`org` 只进了部分流标签）：期望和普通街区一样与边距无关。→ Task 4 把一个中心广场街区、一个中庭街区、一个特色街区加进 `world/window.test.ts` 的 `BLOCKS`，跑已有的 `a block does not depend on the window margin`。
5. **中心区被堵死**（通道口被树 / 长椅 / 游乐设施挡住，或约束修复后断开）：期望从人行道一定能走到中心区。→ Task 4 测试 `centre blocks: a centre zone reachable from the sidewalk`，Task 5 用同一个检查覆盖有内容以后的 12 个街区，Task 6 在世界回归里对所有中心街区检查（`中心可达` 一列）。

   *  the world layer and the generator get the same size whatever prefs / novelty are. blockSeed = `${worldSeed}/${blockId}` */

  export const DISTRICT_CHANCE: Record<ZoneKind, number>;            // calibrated in Step 5
  export const DISTRICT_WEIGHTS: Record<ZoneKind, Record<DistrictKind, number>> = {

  export type Corner = 'NW' | 'NE' | 'SW' | 'SE';
