# tools/

Python 3.12 + [uv](https://docs.astral.sh/uv/) side of the project: flat scripts that (1) reverse-engineer the 46 hand-made reference maps in [`references/`](../references/README.md) into a structured scene JSON, (2) compute the statistics that calibrated the TypeScript generator in [`app/`](../app/README.md), (3) export asset metadata from the tileset in [`assets/`](../assets/README.md) into `app/src/gen/data/*.json`, and (4) render / evaluate / crop generator output without a browser. All intermediate products go to the gitignored [`work/`](../work/README.md); only the `app/src/gen/data/*.json` exports and a few figures under `docs/` are committed.

Every script is run as `uv run python <script>.py` from `tools/`. There is no package API: `pyproject.toml` only pins the dependencies.

## Project files

| Path | Purpose |
|---|---|
| `pyproject.toml` | uv project `citygen-tools`: Python >=3.12, deps numpy, opencv-python-headless, pillow, scipy. The `citygen-tools` console script is an untouched uv-init placeholder. |
| `uv.lock` | Lockfile (numpy 2.5.4, opencv-python-headless 5.0.0.93, pillow 13.0.0, scipy 1.18.1). Regenerated by `uv lock` / any `uv run`. |
| `.python-version` | Pins the interpreter to 3.12. |
| `.gitignore` | Ignores `__pycache__/`, build artefacts and the local `.venv` that `uv sync` creates. |
| `src/citygen_tools/__init__.py` | uv-init placeholder (`main()` prints a hello). Not imported by any script. |
| `common.py` | Shared helpers imported by most scripts: `ROOT`/`ASSETS`/`WORK`/`REFS` paths, `T = 16`, `load_rgba()`, `sheets()`, `singles()`, `cells()`, `META` (refs_meta.json, loaded at import), `load_map()`, `ref_names()`. |
| `refs_meta.json` | Hand-written metadata for the 46 references: `kind` (street 21 / site 19 / showcase 6), `roi` in native px (null = whole image minus 4 px frame), `group` = near-duplicate family kept together in holdouts. |
| `character_themes.json` | Hand-written theme tags for 20 outfit groups and 27 accessories with evidence strings; embedded into `app/src/gen/data/characters.json` by `export_manifest.py`. |
| `run_analysis.sh` | Runs analysis stages 1-3 below in order (`sh run_analysis.sh [ref names...]`); extra args limit the last three steps to those references. |

## Reference analysis pipeline (run order)

Input: `references/*.gif|png` (not published, provide locally) and `assets/` sheets + Singles. Output: everything under `work/`.

| Step | Script | Produces |
|---|---|---|
| 1a | `extract_frames.py` | First frame of every reference -> `work/refs_raw/<name>.png` |
| 1b | `normalize_refs.py` | Detects 2x/3x/4x nearest-neighbour upscale, downsamples to native 1x -> `work/refs/<name>.png` |
| 2a | `build_tile_index.py` | Slices all combined sheets into 16x16 cells, dedupes -> `work/tile_index.npz` + `.json` |
| 2b | `build_catalog.py` | Catalogs every Singles sprite (size, opaque bbox, dup_of) -> `work/catalog.json` + `.csv` (the `sid` id space) |
| 2c | `crop_maps.py` | ROI crop of each reference at 2x -> `work/maps/<name>.png`, to eyeball `refs_meta.json` roi values |
| 3a | `grid_layer.py [names...]` | 16 px grid phase + best base/overlay sheet tile per cell -> `work/grid/<name>.json`, `_bg.png` (slow, Pool(12)) |
| 3b | `grid_objects.py [names...]` | 16-aligned Singles (buildings, fences) matched by tile-id matrix -> `work/grid/<name>_objects.json`; caches `work/sprite_tiles.json` |
| 3c | `detect_objects.py [names...]` | Free-offset Singles via masked template match on unexplained pixels -> `work/detect/<name>.json`, `_overlay.png`, `_residual.png` |
| 4 | `scene.py export [names...]` | Merges grid + detections into the common scene JSON -> `work/scenes/<name>.json`, `_recon.png`, `_diff.png` (not in `run_analysis.sh`) |
| - | `semantics.py` | Rule tables: `sprite_class()` by name keywords, `ground_class()` by tile colour. Imported by `scene.py`, `eval_generated.py`. |

## Statistics on the analysed references

| Script | Purpose |
|---|---|
| `stats.py [street,site]` | Class densities, ground under foot, distance to road/building, class-pair lift, regular rows -> `work/stats/stats.json`, `summary.md` |
| `measure_blocks.py [names...]` | Road widths, sidewalk depths, block extents from scene ground classes (stdout) |
| `ascii_ground.py <names...>` | Per-cell ground classes as ASCII (R road, . paved, B building, g grass, ~ water, s sand, d dirt, ? other, blank unknown) for scenes under `work/scenes/` |
| `novelty.py baseline` / `check <scene.json...>` | 4x4 tile-window copy check and object-constellation repetition; `baseline` calibrates on references, `check` scores scenes. Also a library for `eval_generated.py`. |

## Exports into `app/src/gen/data/` (required order)

| Order | Script | Writes |
|---|---|---|
| 1 | `autotile.py` | 47-blob autotile tables for the six sidewalk terrains -> `work/autotile.json` |
| 1 | `characters.py catalog` | `work/characters/catalog.json` (see above) |
| 2 | `export_manifest.py` | `sprites.json` (18 packs from `work/catalog.json`), `autotile.json`, `modular.json`, `characters.json` (catalog + `character_themes.json`) |
| 3 | `export_opaque.py` | `opaque.json`: 4x4 px opacity masks for buildings matched by its `BUILDING` regex (reads `sprites.json`) |
| 3 | `export_links.py` | `links.json`: left/right seam strips for `5_Floor_Modular_Building` pieces (reads `work/catalog.json`) |
| 3 | `export_refworld.py` | `work/refworld/<name>.json` compact street-reference worlds for `app/scripts/constraints.ts refs` (needs step 4 scenes) |
| 4 | `export_usage.py` | `usage.json`: how often each sprite key appears in `work/refworld` (reads `modular.json`) |

`prefs.json` in the same folder is not produced here; `app/scripts/prefs.ts train` writes it.

## Generated scenes: render, evaluate, crop

Input is generator scene JSON from `cd app && npx tsx scripts/batch.ts ../work/gen 1..12` or the viewer export.

| Script | Purpose |
|---|---|
| `render_generated.py <scene.json...> [--scale 2] [--grid] [--ghost]` | Renders with the viewer draw order -> `<scene>.png` (or `<scene>_ghost.png`) next to the JSON, overwriting |
| `eval_generated.py <scene.json...> [--out report.md]` | Copy / repetition / density / emptiness / blocking metrics against the references as a markdown table (needs `work/tile_index.*`, `work/catalog.json`, `work/scenes/`) |
| `crop_region.py <scene.json> <x0> <y0> <x1> <y1> <out.png> [--pad 32]` | Renders in memory, crops one region with a red box at 2x (used by `app/scripts/prefs.ts gaps`) |
| `deadend_pairs.py <dir> [--pad 64]` | Side-by-side off/on crops of dead-end repairs from `<seed>.rects.json` files (v0.7.5 report) |
| `compare_crops.py <version> <out dir>` | Legacy: run from the shots directory (`cd work/<shots dir> && uv run python ../../tools/compare_crops.py <version> <out dir>`); before/after crops of bad labels from its `off/` and `pd/` 2x shot sets; the `pd` viewer mode is gone since v0.6.1 |

## Commands

| Command | Produces |
|---|---|
| `cd tools && uv sync` | `tools/.venv` with the locked dependencies (first-time setup) |
| `cd tools && sh run_analysis.sh [names...]` | Stages 1-3 into `work/` (refs, tile_index, catalog, maps, grid, detect) |
| `cd tools && uv run python scene.py export [names...]` | `work/scenes/<name>.json` + reconstruction match images |
| `cd tools && uv run python stats.py [street,site]` | `work/stats/summary.md` |
| `cd tools && uv run python novelty.py baseline` | Copy / repetition baseline on the references |
| `cd tools && uv run python autotile.py && uv run python characters.py catalog` | `work/autotile.json`, `work/characters/catalog.json` |
| `cd tools && uv run python export_manifest.py && uv run python export_opaque.py` | `app/src/gen/data/{sprites,autotile,modular,characters,opaque}.json` |
| `cd tools && uv run python export_links.py` | `app/src/gen/data/links.json` |
| `cd tools && uv run python export_refworld.py && uv run python export_usage.py` | `work/refworld/*.json`, then `app/src/gen/data/usage.json` |
| `cd app && npx tsx scripts/batch.ts ../work/gen 1..12` | Generator scene JSON for seeds 1..12 (about 2 s per seed) |
| `cd tools && uv run python render_generated.py ../work/gen/scene_1.json --scale 1` | `work/gen/scene_1.png` (about 1 s) |
| `cd tools && uv run python eval_generated.py ../work/gen/scene_1.json --out ../work/gen/report.md` | Markdown evaluation table (needs the analysis artefacts in `work/`) |
| `cd tools && uv run python make_figs.py` | `docs/reports/fig/*.png` |
| `cd tools && uv run python make_readme_figs.py` | `docs/readme/*.png` |

## Notes

- `work/` is gitignored. On a fresh clone nothing under it exists: run `run_analysis.sh` and `scene.py export` before `export_*.py`, `eval_generated.py`, `make_figs.py` or any statistics script will work. `render_generated.py` and `crop_region.py` need only `assets/` and a scene JSON.
- `references/*.gif|png` (the hand-made maps) are not published; the analysis pipeline needs them placed locally in `references/`. `references/labels/` and `references/choices/` JSON are tracked.
- `assets/` (the 16x16 tileset) is not in the repo either; `common.py` expects it at `<repo>/assets/`.
- `run_analysis.sh` stops after `detect_objects.py`. `scene.py export`, statistics, character scripts and all exports are separate steps, in the order given above.
- `export_manifest.py` must run before `export_opaque.py` and `export_usage.py`; `export_refworld.py` must run before `export_usage.py`.
- Delete `work/sprite_tiles.json` after re-running `build_tile_index.py` or `build_catalog.py`; `grid_objects.py` would otherwise use stale tile ids.
- `grid_layer.py` is the slow step (full phase search, KD-tree per cell, Pool(12)). Pass reference names to limit the work.
- `render_generated.py` writes next to its input and silently overwrites same-named PNGs.
- Run scripts from `tools/`: `uv run` needs the project here, `common.py` is resolved from the script directory, and `decomp_example.py` hard-codes `../assets/exteriors/` (exception: `compare_crops.py` runs from the shots directory, see its row).
- `extract_frames.py` and `inspect_refs.py` only read `*.gif` / `*.png` in `references/`, so `references/README.md` and the `labels/` / `choices/` folders are ignored.
- Some scene JSON contains Chinese labels; ad-hoc Python reading it on Windows needs `encoding='utf-8'` or `python -X utf8`. The repo scripts already handle this.
